# Ustaz BilimAI — информатикадан ҰБТ-ға дайындық

**Нысана — бұрынғы https://ustaz-bilimai.vercel.app/ мекенжайы және сол Supabase жобасы.** Өзгерістер [PR №1](https://github.com/sss270186-cyber/ustaz-bilimai/pull/1) ішінде. Production дерекқоры өзгертілмеді, PR біріктірілмеді, жаңа нұсқа Production-ға жарияланбады.

## Қазіргі нұсқа

- 19 тақырып: толық теория, формула/ереже, мысалдар және өзіндік тексеру.
- Әр тақырыпта 2 B және 10 C; барлығы **228 авторлық тапсырма**. Күрделі көпқадамды есептер мен Python, SQL, HTML/CSS, Excel, IP, логика талдауы.
- Жеке «Тексеру»; дұрыс жауап, шешу қадамдары, түсіндірме және қатені талдау серверлік тексеруден кейін ғана ашылады.
- Supabase Authentication арқылы бұрынғы мұғалім/оқушы аккаунттары; ортақ нәтижелер Supabase-те, оқушыға тек өз нәтижесі.
- Мұғалімнің оқушы тіркеуі, өз тобы, тақырып бойынша қателер, тапсырма редакторы/нұсқалары, жасыру/ашу және CSV есеп.
- Өзіндік құпиясөз өзгерту, мұғалімнің өз оқушысына жаңа құпиясөз беруі, ескі сеанстарды шектеу.
- Телефон және компьютер интерфейсі. ҚМЖ жаңа сайттан алынды.

**[Бұрынғы Vercel-де іске қосудың нақты тәртібі](docs/VERCEL-RELEASE.md)** — иесіне арналған негізгі құжат. Жаңа Preview, Sites жариялауы, PostgreSQL орнату қажет емес. Соңғы SQL/панель/merge әрекеттері тек Production-ға бөлек рұқсаттан кейін орындалады.

## Орналастыру құрылымы

`index.html`, `assets/`, `student.js` — статикалық интерфейс. `api/*.js` — алты Vercel Node функциясы. `supabase/migrations/` — реттелген алты миграция. `supabase/releases/20261026_initial_release.sql` — тек бұрын оқу жүйесі орнатылмаған бастапқы жобаға арналған бір транзакциялы орнату. Жетілдірілген жауаптар тек `unt_private` ішінде, service-role кілті тек серверде. RLS және серверлік RPC рөлді, нәтижелерді және бағаны қорғайды.

Бұрынғы Sites/D1 және preview worker коды белсенді жобадан алынды, Git тарихында сақталған. Нақты аккаунттар көшірілмейді, бұрынғы Supabase Auth сақталады. Бұрынғы кестелер жойылмайды. Профиль рұқсаттарын қатайту ескі браузердегі профиль өңдеуге әсер етуі мүмкін; толық сипаттама негізгі жариялау құжатында.

## Әзірлеушінің жергілікті тексеруі

Пайдаланушыға бұл бағдарламаларды орнату талап етілмейді. Әзірлеушіге Node.js 24, Python 3, Chromium қажет.

```sh
npm ci
npm run check
npm run seed:check
npm test
npm run build:vercel
npm run test:programs
npm run test:excel
npm run test:ui
npm run test:css
```

`npm run build:vercel` тек рұқсат етілген сайт файлдары мен алты функцияның орналастыру көздерін `work/vercel-release` ішіне дайындап тексереді; Vercel-дегі бұлттық deploy-ды орындамайды. SQL генераторлары базамен байланыспайды. Нақты Supabase пен Vercel-ге қолмен қосу тек жариялау рұқсатымен жүргізіледі.

`npm run dev:local` жергілікті PGlite PostgreSQL мен айқын белгіленген Auth эмуляторын іске қосады. Тек тест: мұғалім `teacher@local.test`, оқушы `student01`, құпиясөз `LocalDemo-Only-2026`. Бұл деректер нақты сайтқа жарияланбайды; жергілікті сервер қайта басталғанда тест базасы тазарады. Өндірістік құпиялар оқылмайды.
