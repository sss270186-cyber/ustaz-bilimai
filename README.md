# Ustaz BilimAI

Информатикадан ҰБТ-ға дайындық. Бірінші кезең: ортақ интерфейс және «Ақпаратты өлшеу».

## Іске асырылғаны

- Қазақ тіліндегі бейімделетін интерфейс, 19 тақырыптың мәзірі. Қалған 18 бөлім «Дайындалуда» деп белгіленген.
- «Ақпаратты өлшеу»: толық теория, B деңгейіндегі 2 және C деңгейіндегі 10 авторлық тапсырма; берілгені, ізделетіні, формулалар, жеке жауап өрісі мен тексеру батырмасы.
- Жауапты PostgreSQL функциясы тексереді. Нәтиже сақталғаннан кейін дұрыс жауап пен қадамдық шешім беріледі.
- Оқушының нәтижелері; мұғалімнің тобы, алғашқы қате кеткен тақырыптар, оқушы тіркеу және тапсырманы жасыру/ашу.
- Бұрынғы email/логин тәсілі, `profiles`, Auth аккаунттары және ҚМЖ үлгісі сақталған. `app.py` өзгермеген.

**Бұл код әлі Production-ға жарияланбаған.** Жаңа кабинетті іске қосу үшін қосымша миграцияларды staging-де тексеріп, кейін тірі жобаға қолдану керек. Қолданыстағы дерекқорға осы жұмыс барысында жазу жасалмады.

## Тексеру

Node.js 24 ұсынылады.

```sh
npm ci
npm run check
npm run seed:check
npm test
npx playwright install chromium
npm run test:ui
```

Жүйелік Chromium қолданылса: `BROWSER_EXECUTABLE=/usr/bin/chromium npm run test:ui`.

`npm test` — оқшауланған PGlite PostgreSQL, RLS, API және есеп жауаптарының тесттері. `test:ui` — нақты браузерде жалған Auth/API деректерімен орындалатын smoke test; Supabase-ке қосылмайды. GitHub Actions тек тексерулерді орындайды, миграция немесе deployment жасамайды.

## Құрылым

- `index.html`, `assets/`, `student.js` — жария клиент.
- `api/` — Vercel сервер функциялары; әкімшілік кілт тек оқушы тіркеу функциясында.
- `supabase/migrations/` — тек жаңа оқу кестелері мен функцияларын қосатын екі миграция.
- `scripts/measurement.cjs` — жабық авторлық тапсырмалар көзі; `build-seed.cjs` одан SQL жасайды.
- `app.py` — бұрынғы бөлек Streamlit нұсқасы; жаңа Vercel оқу жүйесіне қосылмаған.

Тек `vercel.json` жариялауға рұқсат берген файлдар static output-қа кіреді. Репозиторий түбірін жай static hosting арқылы жариялауға болмайды: онда жабық SQL seed, тесттер және бұрынғы Streamlit кодында жауаптар бар.
