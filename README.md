# Ustaz BilimAI — информатикадан ҰБТ-ға дайындық

PR №1 ішіндегі әзірлеу нұсқасы. **Production, бұрынғы Supabase және пайдаланушы аккаунттары өзгертілмейді. PR бөлек рұқсатсыз біріктірілмейді.**

## Мазмұн

19 тақырыптың әрқайсысында теория, B деңгейіндегі 2 және C деңгейіндегі 10 авторлық тапсырма бар: барлығы **228 тапсырма**. Теория мақсаттар, түсіндіру бөлімдері, формулалар/ережелер, мысалдар, өзіндік тексеру сұрақтары және анықтамалық сілтемелерден тұрады.

Әр тапсырмада берілгені, ізделетін шама, формула/ереже, жеке жауап өрісі және «Тексеру» бар. Дұрыс жауап, шешуі мен түсіндірме тек серверлік тексеруден кейін беріледі. Сан, мәтін, IP/код және тізбек жауаптары қолданылады; оқушы енгізген код серверде орындалмайды.

Тақырыптар: аппараттық/программалық жасақтама, жад, ақпарат өлшеу/алфавиттік көлем/кодтау, санау жүйелері, желі/өткізу қабілеті/IP/DNS, логика, Excel, Python алгоритмдері/функциялары, HTML/CSS, SQL, ЖИ және нейрондық желілер.

## Supabase-сіз жергілікті сынақ

Node.js 24 және Python3 ұсынылады.

```sh
npm ci
npm run dev:local
```

`http://127.0.0.1:4173` ашыңыз. Мұғалім: `teacher@local.test`; оқушы: `student01`. Екеуінің **тек жергілікті сынаққа арналған** құпиясөзі: `LocalDemo-Only-2026`.

Бұл режим оқшауланған PGlite PostgreSQL базасында бес миграцияны орындайды және сол SQL grading/RLS функцияларын пайдаланады. Auth — localhost эмуляторы, нақты Supabase Authentication емес. Сары баннер режимді анық көрсетеді. Нәтижелер сеанс/бетті жаңартудан кейін сақталады, бірақ сервер қайта іске қосылса жадтағы деректер тазарады. Production айнымалылары оқылмайды, сыртқы API-ге сұрау жіберілмейді. Интернетке жариялау үшін арналмаған.

## Тексеру

```sh
npm run check
npm run seed:check
npm test
npm run test:programs
npm run test:excel
npx playwright install chromium
npm run test:ui
npm run test:css
```

Жүйелік Chromium үшін соңғы командаларға `BROWSER_EXECUTABLE=/usr/bin/chromium` қосуға болады. `npm test`: 67 тест, оның ішінде барлық 228 жауапты PostgreSQL grading арқылы өткізу, Preview оқшаулауы және қауіпсіз staging bootstrap. `test:programs`: 36 Python/SQL кодын орындау және IP-ді stdlib модулімен тексеру. `test:css`: 12 HTML/CSS жауабын нақты браузерде есептеу. `test:ui`: 19 бөлім, 228 тапсырма карточкасы, жауап/шешім, сақтау, мұғалім кабинеті, жаңа жергілікті аккаунт, деректер оқшаулануы және mobile.

## Hosted жүйеге дайындау

Бес SQL файл ретімен қолданылады:

1. `202610180001_learning.sql`
2. `202610180002_measurement_seed.sql`
3. `202610180003_answer_formats.sql`
4. `202610180004_full_curriculum.sql`
5. `202610180005_quality_review.sql`

Алғашқы екі миграция өзгертілмеген. 003 және 004 жаңа answer formats, code, түсіндірме және қалған 216 тапсырманы қосады; 005 сапа жаңартуын, қате жауап талдауын және тапсырма нұсқаларын сақтауды қосады. Ескі нәтижелер мен аккаунттар жойылмайды. **Осы жұмыста тірі базаға ешбір миграция қолданылған жоқ.**

`api/` — Vercel сервер функциялары; `unt_private.answer_keys` — жабық жауап кілттері. `assets/lessons.js` тек ашық теорияны қамтиды. `scripts/curriculum/` және SQL seed — авторлық жабық орындаушы материалдары; пайдаланушының нақты рұқсатымен ашық GitHub-та сақталады, бірақ сайттың static output-ына кірмейді. Қарапайым static сервермен репозиторий түбірін жарияламаңыз. `vercel.json` тек клиент файлдарын explicit allowlist арқылы береді.

Қолданыстағы логин/email пішімі, ҚМЖ үлгісі, `localStorage.bilimai_results` және бөлек `app.py` сақталған. Мұғалім жаңа оқушы тіркеп, нәтижелерін көріп, тапсырманы жасырып/аша алады. Толық тапсырма редакторы, еркін код орындау, бірнеше ұйымға арналған иелік шекаралары және production интеграциясы әлі жасалмаған.

Іске қосуға дайындықтың қазіргі есебі: [docs/READINESS.md](docs/READINESS.md). Free тарифіндегі DB/Auth backup және restore: [docs/BACKUP.md](docs/BACKUP.md). Браузердегі бөлек Supabase/Vercel Preview қадамдары: [docs/STAGING.md](docs/STAGING.md). Preview тек бөлек базаға қосылуы үшін `BILIMAI_STAGING_SUPABASE_URL` міндетті; қате баптауда API Supabase-ке сұрау жібермей 503 береді. Нақты backup/restore және hosted staging әлі орындалмаған. Бұрынғы кезеңдер есебі тарихи құжат ретінде сақталған.
