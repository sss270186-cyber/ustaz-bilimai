## Нақты қамтылған қорғаныс

- 228 тапсырманың дұрыс және қате жауаптары нақты жергілікті PostgreSQL функциясымен тексерілді.
- Бұрынғы жасанды Auth пайдаланушылары мен профильдер алты миграциядан кейін сақталды. Бір транзакциялы орнату және қайталап орнатудан бас тарту тексерілді.
- Ескі рұқсаты кең профиль саясаты бар жағдайда да оқушы басқа профильді оқымайды, мұғалім рөлін алмайды, жауап кілтін/әрекеттерді жаза алмайды.
- Мұғалім тек өз оқушыларын көреді, басқа мұғалімнің оқушысын топқа қоса немесе паролін ауыстыра алмайды. Қолдан жасаған user/topic/level өрістері сенімді деп қабылданбайды.
- Тапсырма өңделгенде бұрынғы жауап кілті мен нұсқасы сақталады; бұрынғы нәтиже өзгермейді. Ескірген редактор өзгерісті үстінен жазбайды.
- Пароль жаңартылғанда ескі және refresh жасалған ескі сеанс оқу деректеріне кірмейді; жаңа кіру рұқсат алады. Жүйеден шыққанда редактордағы жауап пен пароль өрістері тазаланады.
- CSV тек мұғалім тобына қатысты; кестелік формулалар арқылы орындалатын енгізулер бейтараптандырылады.
- Кірусіз/оқушы JWT-мен аккаунт жасауға болмайды. API мен браузерге әкімшілік кілт берілмейді.
- Бұрынғы оқушы логині/email сәйкестігі негізгі `main` тармағындағы кодпен салыстырылды және сақталды.

## Орындалмағаны

**Нақты Supabase базасына миграция орындалмады; Production пайдаланушысы тіркелмеді/паролі өзгертілмеді; PR біріктірілмеді; Vercel Production deployment жасалмады.** Қосымша Preview немесе Sites сайты жасалған жоқ.

Жергілікті браузер Auth эмуляторын пайдаланады; бұл нақты Supabase кіруін растау емес. Осы ортадан нақты дерекқор сұлбасын тек оқуға арналған сұраумен растау да байланыс шектеуіне байланысты аяқталмады. Vercel басқару қолжетімділігі жоқ: бұлттағы нақты build, бұрынғы аккаунтпен кіру және тариф/жоба баптаулары жариялау кезінде панельде тексеріледі. Жергілікті source package дайындау Vercel бұлттық build-ы өтті дегенді білдірмейді.

Иесіне тек браузердегі соңғы әрекеттер қалады: [бастапқы жобаны тексеру және рұқсаттан кейін SQL қосу, үш Vercel айнымалысын тексеру, бөлек рұқсатпен PR біріктіру](VERCEL-RELEASE.md). Бағдарлама орнату талап етілмейді.
