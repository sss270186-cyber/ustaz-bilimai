# Толық оқу мазмұны — жергілікті әзірлеу кезеңі

## Шекара

Жұмыс PR №1 ішінде жалғасады. Интеграцияларға қосымша рұқсат сұралмайды және олар күтілмейді. Production сайт, тірі Supabase, бұрынғы мұғалім/оқушылар өзгертілмейді; main-ге merge жасалмайды. Hosted backup/staging жасалды деп белгіленбейді.

## Кезеңдер

1. Бұрын дайын «Ақпаратты өлшеу» қайта тексерілді:27 тест және браузер сынағы өтті.
2. Қалған18 тақырыпқа толық теория және216 тапсырма қосылды. Алғашқы12 тапсырмамен бірге19×12=228. Әр тақырып:2 B,10 C.
3. Мәтін, тізбек, бинарлық/hex код және IP сияқты жауаптарға қауіпсіз серверлік салыстыру қосылды. Сандық жауап exact numeric арқылы тексеріледі. Дәлдік шартта көрсетілген жағдайда ғана авторлық жауап дөңгелектелген.
4. Жергілікті sandbox пен кеңейтілген мазмұн тексерулері қосылды.

## Жауаптардың тексерілуі

- 52 Node/PostgreSQL тесті: тапсырма құрылымы,19 тақырып×12 жауаптың SQL функциясымен дұрыс тексеріліп сақталуы, құпия кілт шекарасы, RLS, teacher/student isolation, алғашқы әрекет, old data preservation, rate limit және staging guards.
- Арифметикалық, биттік, комбинациялық және метрика жауаптары авторлық файлдан бөлек есептеу модельдерімен салыстырылған. Түсіндірмелердің математикалық мағынасы да мазмұнды шолу барысында қаралды; автоматты тест педагогикалық сараптаманы толық алмастырмайды.
- Авторлық Python/функциялар коды24 тапсырма және SQL12 тапсырма нақты Python/SQLite арқылы орындалды. SQL ортақ SELECT синтаксисін қолданады; hosted grading PostgreSQL-де бөлек тексерілді. Оқушы кодын eval/execute жасау жоқ.
- IP есептері Python `ipaddress` арқылы қайта есептелді. Барлық12 HTML/CSS жауабы Chromium DOM/computed-style/layout арқылы тексерілді.
- Браузерде19 теория,228 карточка, сан/тізбек/IP grading, тек тексеруден кейін solution/explanation, reload кейінгі сақтау, мұғалім hide/show, жаңа local аккаунт және оқушы нәтижесінің оқшаулануы тексерілді.
- Аудитте табылған қателер түзетілді: Хэмминг аралығы4, қос цикл жинағы30, блок-схема тармақтарының соңғы мәні13. Негізді табу мысалы бүтін негіз беретін шартқа келтірілді. Шексіз ондық период беретін екі есеп дәл ондық мәндермен ауыстырылды; дөңгелектеу қолданылған жерде дәлдік шартта жазылды.

## Жұмыс істейтін жергілікті нұсқа

`npm run dev:local` localhost-та isolated PGlite ашады. Төрт SQL миграция бірден орындалады. Жауаптар браузерге алдын ала жіберілмейді, PostgreSQL-де тексеріледі. Auth жергілікті эмулятор екенін баннер анық көрсетеді. Бұл нақты Supabase Auth сынағы не Production deployment емес. Дерек RAM-да: server restart кезінде тазарады, page reload/қайта кіру кезінде сақталады.

## Дайын емес

Hosted DB/Auth backup/restore, нақты Supabase интеграциясы, Vercel Preview-дің бөлек staging-пен end-to-end байланысы орындалмаған. Толық мұғалім тапсырма редакторы, оқушының еркін кодын орындау, бірнеше ұйымға tenant isolation және үлкен тарихты беттеу жоқ. Ресми ҰБТ спецификациясымен сыртқы сараптама жүргізілген жоқ; материалдар авторлық дайындық жинағы болып белгіленеді.

Теория мен тапсырмалар жергілікті тексерілген әзірлеу мазмұны; Production-да ашылғанын білдірмейді. Шешімді көргеннен кейінгі қайталау тәуелсіз емтихан бағасы емес.
