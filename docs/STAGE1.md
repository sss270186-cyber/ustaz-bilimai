# Бірінші кезең туралы есеп — 2026-10-18

## Бастапқы күй

Репозиторийдің `main` commit-і: `f9cc0a518d326e0831b152e1e88b643175e5a597`.
Бастапқы файлдар: `index.html`, `student.js`, `api/config.js`, `api/students.js`, `app.py`, `requirements.txt`.

Vercel сайты Supabase Authentication-пен мұғалім email-ін және оқушының `логин@students.ustaz-bilimai.example.com` ішкі email-ін қолданады. Мұғалім оқушыны серверлік Admin API арқылы жасайды. `profiles` рөлі, `is_teacher()` RPC қолданылады. Демо тесттің жауаптары браузерге жіберілген, нәтижелері `localStorage.bilimai_results` ішінде ғана сақталған. ҚМЖ бөлімі — қарапайым үлгі құрастырушы. `app.py` — бөлек Streamlit материалы, бірыңғай Auth/нәтиже жүйесіне қосылмаған.

Тірі Supabase-ке **тек GET сұраулары** жасалды: 2 профиль (1 teacher, 1 student); анонимді сұрау профиль жолдарын қайтармады; жаңа `unt_topics` кестесі жоқ (404). Бұл барлық ескі RLS саясаттарын толық аудиттеу емес. Аккаунтпен нақты кіру тексерілмеді. Пайдаланушылар тізімі мен құпиясөздер файлдарға шығарылған жоқ.

## Жасалған өзгерістер

- Бейімделетін интерфейс, ашық теория, 19 бөлім. Іске қосуға дайын мазмұн — тек «Ақпаратты өлшеу».
- 2 B + 10 C қайталанбайтын тапсырма, жеке тексеру, сервер жауабынан кейін қадамдық шешім.
- `unt_private.answer_keys` жабық кестесі, `unt_…` қосымша кестелері; клиенттің тікелей нәтиже жазуына тыйым салынған.
- Сервер RPC пайдаланушыны JWT арқылы анықтайды. Тапсырма ID мен жауапты ғана қабылдайды; клиент ұпай/оқушы ID тағайындамайды. Тексеру мен нәтиже жазу бір транзакцияда.
- Бір минутта бір аккаунтқа 20 тексеру; бос/жарамсыз сан сақталмайды. Дәл сандық салыстыру, үтір/нүкте және разрядтық бос орындар қабылданады. Өлшем бірлігін өріске енгізуге болмайды.
- Алғашқы әрекет бойынша статистика, соңғы 200 әрекет, мұғалім тобына ғана нәтиже, тапсырманы жасыру/ашу.
- Жаңадан жасалған Auth аккаунтының профилі жазылмаса, аккаунт енді жойылмайды: ішінара аяқталған әрекет туралы нақты қате беріледі. Әкімші профильді қалпына келтіреді. Оқу тобына қосу сәтсіз болса, тіркелген аккаунт сақталады.
- ҚМЖ үлгісінің бұрынғы мазмұны мен жергілікті демо нәтижелері сақталған. Streamlit файлы өзгермеген.
- Static output-қа жеке файлдардың explicit тізімі ғана кіреді; CSP қосылған, inline script қолданылмайды.

## Тексерулер

- **22 автоматты тест өтті:** есептердің тәуелсіз арифметикасы; PostgreSQL миграциясы мен RLS; қате/дұрыс жауапты сақтау; жеке нәтиже шекарасы; мұғалім құқығы; алғашқы әрекет статистикасы; жиілік шектеуі; API validation, сервер кілтінің шекарасы, желі қатесі, ескі аккаунт басқару fallback-і және ішінара тіркеуде дерек сақталуы.
- JavaScript синтаксисі, HTML идентификаторлары, CSP-ге сәйкес inline кодтың жоқтығы, жария файлдар және seed сәйкестігі тексерілді.
- Chromium: desktop 1440×1000 және mobile 390×844. Оқушы/мұғалім кіруі, B/C тексеру, шешім, нәтиже, топ тізімі, жасыру, шығу, ҚМЖ HTML escape, мобильді мәзір және көлденең overflow тексерілді. **Auth/API — сынақ fixtures**, тірі Supabase емес.
- GitHub Actions workflow қосылды; remote CI нәтижесі бөлек тексеріледі.

## Дайын емес және расталмаған

Жаңа SQL тірі Supabase-ке қолданылған жоқ. Vercel Preview/Production-ға осы жұмыста deployment жасалмады. Vercel build artifact-інің нақты private-file exclusion-ы және нақты Supabase Auth-пен интеграциясы Preview-де қабылдау тексеруін қажет етеді. Жергілікті тесттер production интеграциясының орнына жүрмейді.

Қалған 18 тақырып, мұғалімнің тапсырманы толық жасау/мәтінін өңдеуі, оқушы кодын орындау, бірнеше ұйымды бөлу әзірше жасалмаған. Жаттығуда шешім бір әрекеттен кейін ашылатындықтан, қайталау нәтижесі тәуелсіз емтихан бағасы болып саналмайды.

Орнату, backup және қабылдау тізімі: `docs/ROLLOUT.md`.
