## Қалай қарап көруге болады?

1. Жоғарыдағы **«Оқушы болып көру»** батырмасын басыңыз.
2. Тақырыпты таңдап, **«Тапсырмалар»** бөліміне өтіңіз. B — 2 есеп, C — 10 есеп.
3. Жауабыңызды енгізіп, **«Тексеру»** басыңыз. Содан кейін дұрыс жауап, қадамдар және түсіндірме ашылады. Қате жауапта қатені талдау бар.
4. **«Мұғалім болып көру»** арқылы осы браузердегі сынақ оқушысының нәтижесін көріңіз. Жасанды оқушы тіркеуді және тапсырманы жасырып/ашуды да тексере аласыз.

Мысалы, «Python» деп іздеп, күрделі есепті ашуға болады. Тақырып жанындағы белгі осы сынақ оқушысының орындалған есеп санын көрсетеді. Бет жаңарса да нәтижелер осы браузерде қалады.

## Нақты шекарасы

- 19 теория, 38 B және 190 C: 228 тапсырма PR №1-дегі тексерілген материалдан алынады.
- Жауаптар Preview серверінде тексеріледі. Дұрыс жауаптар мен шешімдер алдын ала клиентке жіберілмейді. Бос/жарамсыз жауапқа шешім берілмейді.
- Оқушы/мұғалім батырмалары **сынақ режимін** ауыстырады. Бұл нақты Supabase Authentication емес; Production аккаунттары қосылмаған.
- Сынақ тарихы мен жасанды аккаунттар **осы браузерде** сақталады. Құрылғылар арасында көшпейді; браузер деректерін тазаласаңыз жойылады. Local storage бұғатталған жағдайда тарих тек ашық бет жадында сақталады және хабарлама көрсетіледі. Нақты оқушының аты-жөнін немесе шынайы паролін енгізбеңіз.
- Жасанды аккаунт паролі болса, тек оның SHA-256 хеші браузерде сақталады. Бұл Production пароль қорғанысының орнына жүрмейді; тұрақты жүйе Supabase Auth қолданады.
- Мұғалім нәтижені осы браузердегі барлық synthetic оқушы үшін көреді. Бұл Preview-де нақты оқушыларға қолжетімділік/ұйым оқшаулауы сыналды дегенді білдірмейді. Негізгі Supabase RLS/API тексерулері бөлек сақталған.
- Preview сервері Supabase/Vercel credentials қолданбайды және сыртқы қызметке сұрау жібермейді. Клиенттің желілік саясаты тек осы сайтқа қосылуға рұқсат етеді.
- Сынақ сайты жеке Sites жобасында орналасқан. Бұрынғы Ustaz BilimAI Production домені, Supabase және main тармағы өзгертілмеген. PR №1 біріктірілмеген.
- ҚМЖ бөлімі бұрынғы қарапайым үлгі ретінде сақталған. Толық тапсырма редакторы және еркін Python/SQL орындау әлі іске қосылмаған.

## Тексеру нәтижесі

- **71/71** автоматты тест өтті: бұрынғы 67 және Preview-ге арналған 4 қосымша тест.
- Негізгі SQL grading және жаңа Preview grading үшін 228 дұрыс, 228 қате жауаптың бәрі тексерілді.
- Жарамсыз жауаптың шешімді ашпайтыны, catalog-та private өрістер жоқтығы және сервер бастапқы коды сайттан жүктелмейтіні тексерілді.
- Chromium: 19 бөлім/228 карточка, тақырып іздеу, нақты серверлік жауап тексеру, қате талдауы, қайта жүктегенде тарих, demo режимдері, жасанды оқушы, тапсырманы жасыру/ашу және мұғалімнің 390 px телефон көрінісі өтті.
- Браузер сынағында сыртқы желілік сұрау болған жоқ.
- Негізгі платформаның SQL/RLS/API, 36 Python/SQL, 12 Excel, 12 HTML/CSS және интерфейс тексерулері де қайта өтті.
- Жарияланған нұсқа тексерілген Worker артефактісінен құрастырылды; hosting қызметі deployment нәтижесін `succeeded` деп растады. Браузерлік QA жергілікті сол кодпен орындалды; жарияланған жеке сайтқа пайдаланушының нақты кіруі осы есепте орындалды деп көрсетілмейді.

## Әзірлеушіге

`preview/build.cjs` қазіргі оқу материалдары мен client assets-тен standalone Worker құрастырады. `preview/worker.mjs` private кілттерді тек server bundle-де ұстайды, catalog үшін explicit public field allowlist қолданады, тек POST grading жауабында бір тапсырманың шешімін қайтарады. Сандық тексеру float емес, decimal жолын дәл нормалау арқылы орындалады. `preview/sdk.js` тек осы сынақ сайтында қолданылатын, browser-local demo адаптері; Production static allowlist бұл каталогты жарияламайды.

`npm run test:preview` browser QA; `npm test` ішінде Preview server тесттері орындалады. Sites Worker ESM starter-інің build және artifact validator файлдары пайдаланылды. Осы орындауда plugin workflow helper-лері executor-да болмағандықтан source қысқа мерзімді native credential арқылы жүктелді; credential тек stdin/процесс жадында қолданылды, source/archive/логқа сақталған жоқ.

Backup, hosted staging және PostgreSQL орнату жұмыстары пайдаланушының соңғы нұсқауымен **тоқтатылды**. Ескі нұсқаулықтар болашаққа сақталған; Preview қарау үшін оларды орындау талап етілмейді. Production-ға көшу кейін бөлек қарастырылады.
